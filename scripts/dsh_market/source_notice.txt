The bundled catalog normalizes public registry metadata. Its registry commit
is not any individual plugin's source commit. Upstream verification, authors,
licenses, counts, and descriptions are source claims, not an AAG security audit.
Original descriptions are excerpted to 400 Unicode code points. Missing English
or Chinese translations remain missing. AAG's keyword labels are heuristic.
Description fields are privacy-scrubbed before publication. Email addresses,
authenticated URLs, absolute user-profile paths, RFC1918/CGNAT addresses, and
Tailnet hostnames are replaced with stable redaction tokens. Source repository
and author attribution remain unchanged. The bundled snapshot records per-class
replacement counts and the number of modified entries; no entry is silently
dropped.

The current bundled snapshot was re-scrubbed offline from the previously
normalized snapshot at the recorded immutable registry commit. No network
request, translation, plugin installation, or plugin execution occurred during
that public-snapshot repair.

The collector is an independent bounded adapter; it does not execute upstream
collection scripts, install packages, create schedules, or run plugin code.
