# AAG v0.2.0 Preview

This preview aligns the npm browser UI with the Tauri desktop application and
closes the Phase 23 state-lifetime repairs. Native release candidates are
unsigned. The release badge indicates build mode, not platform certification.

## Changes

- Route saves, batch deletion, dragging, upstream toggles, and pin/unpin use
  current state. Pool and route state have separate responsibility boundaries.
- Gateway status distinguishes stopped, running, degraded, and unknown states
  and rejects stale health responses. Keys are masked by default.
- Route columns align with their controls. Header and table layout adapt to
  smaller viewports, with stable light and dark theme coverage.
- npm source/demo builds and Tauri builds use the same UI and desktop version.
  The demo output cannot overwrite the native frontend bundle.
- A shared vector brand generates the favicon, native PNG/ICO/ICNS assets, and
  macOS tray template. Build badges make demo/development/release mode explicit.
- Close-to-tray behavior depends on successful tray installation. The isolated
  Codex Desktop mirror reports unsupported platforms before writing state.
- The Rust startup regression now makes a real bounded HTTP health request to
  the actual ephemeral listener before shutdown.
- Anthropic-compatible routes preserve thinking blocks, opaque signatures,
  signature deltas, cache metadata, and event order. Streaming token usage is
  normalized instead of being reported as zero.
- Upstream providers reuse HTTP clients and expose content-free stage timing.
  An in-app Diagnostics dialog enables Debug for 30 minutes with bounded local
  log rotation and native/frontend lifecycle evidence.

## Distribution Boundary

The Windows preview is unsigned and requires the WebView2 runtime. Any attached
installer is a packaging candidate, not proof of install/upgrade acceptance.
Do not disable operating-system protections to run it. The browser demo uses
synthetic data and is not a substitute for the native gateway.

A manual build matrix covers Windows x64, macOS Intel/Apple Silicon, and Linux
x64. A platform is built only when its job succeeds; availability in the matrix
does not prove native launch, tray, deep-link, CLI, or upgrade behavior. macOS
notarization, Windows signing, automatic updates, real upstream integration,
and measured rendering-performance improvements remain outside this preview.
No dependency lockfile is tracked. A local `ui/package-lock.json` may exist but
is ignored, so rebuilds are reproducible from manifests only.

## Run from Source

From the repository root after installing its dependencies and the UI dependencies:

```text
npm run ui:demo
npm run ui:preview
npm run desktop:dev
npm run release:verify
npm run desktop:build
```

The root `npm run dev` continues to launch the headless Node TUI. Close and
relaunch an already running native AAG instance to use a newly built executable;
the single-instance plugin can otherwise focus the old process.

Before replacing an existing app, exit AAG and back up its application data
directory and any agent configuration files to be switched. No schema migration
is introduced. Keep the prior binary and backup for rollback.
